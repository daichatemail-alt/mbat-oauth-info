Privacy policy

MBAT Gmail Read Only · Updated 28 October 2026

This policy describes the personal Windows desktop tool's Gmail ingestion. It is intended only for its operator's dedicated Gmail account, dai.mbat.leads@gmail.com.

Access and purpose

The tool requests only https://www.googleapis.com/auth/gmail.readonly. It searches and reads selected forwarded promotional messages to extract offer terms, preserve provenance and distinguish original sender and date from forwarding details. It records message identifiers, relevant message content, extracted terms, ambiguity and assessment history for auditing and manual review. It does not change email or open external email links or attachments.

Storage and sharing

The normal ingestion pipeline stores its evidence and refresh credentials locally using Windows user-bound DPAPI encryption and restricted file permissions. Access tokens are held in memory. Gmail data is obtained from Google over HTTPS. The ingestion pipeline does not send message content to AI services, advertising services, bookmakers or exchanges, and does not sell Gmail data. Real email, identifiers and credentials are excluded from source control and automated CI tests. Operator-created copies and backups require separate protection and retention controls.

Retention and control

The evidence store has a fixed retention lease, normally 30 days, configurable from 1 to 90 days. Expiry blocks further collection; it does not automatically delete stored data. The operator must explicitly retire the expired managed store. This does not delete email in Gmail, independently saved copies, backups or refresh credentials. Credentials remain locally until removed by the operator; Google permission can be revoked through Google Account settings. Revocation stops future authorized access but does not erase existing local evidence.

Device and backup encryption must be checked separately. Copying Windows user-bound encrypted files alone is not a verified recovery method on another computer.

Google user data

The tool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For access, deletion or privacy questions, contact the operator at dai.mbat.leads@gmail.com.

Information website hosting

If these information pages are hosted on GitHub Pages, GitHub logs visitor IP addresses for security purposes. The pages themselves contain no analytics scripts, advertising, forms or Gmail sign-in. See GitHub's privacy statement for the hosting provider's practices.
