Privacy policy

MBAT Gmail Read Only · Updated 28 October 2026

This personal desktop tool requests Gmail read-only access (gmail.readonly) to search and read selected promotional emails in its operator's dedicated account. It stores relevant message content, identifiers and extracted information for manual review and audit. It does not send, modify or delete email.

Email data and saved authorization credentials are encrypted locally using Windows user-bound protection and restricted file permissions. The ingestion pipeline does not sell or share email data with third parties, upload it to AI services, or include it in source code or automated tests.

Stored email evidence normally has a 30-day retention lease. Expiry stops collection; the operator must explicitly delete the expired managed store. Credentials remain until removed. Google access can be revoked in Google Account settings; this does not erase existing local data. Independently saved copies and backups require separate deletion.

The tool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This information site has no analytics or forms. GitHub Pages logs visitor IP addresses for security; see GitHub's privacy statement.
